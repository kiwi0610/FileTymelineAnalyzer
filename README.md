# FileTymelineAnalyzer 🔍

Edukativni Java alat iz oblasti digitalne forenzike za brzo generisanje hronološkog pregleda (timeline-a) aktivnosti fajlova i foldera u izabranom direktorijumu.

## 📌 O projektu

Program omogućava da se unese putanja do određenog foldera i dobije pregled fajlova ili foldera sortiranih po vremenu poslednje izmene, od najstarijeg ka najnovijem. Koristan je za brzu orijentaciju prilikom analize foldera i razumevanje redosleda promena.

## ✨ Karakteristike

* **Forenzička primena:** Brzo uočavanje poslednjih promena u zadatom folderu.
* **Bez menjanja podataka:** Alat samo čita metapodatke, ne menja fajlove i ne ostavlja tragove na sistemu.
* **Jednostavno pokretanje:** Dovoljno je uneti putanju do foldera u konzoli.

## ▶️ Pokretanje

Projekat se otvara u IntelliJ IDEA-i i pokreće iz odgovarajuće klase (ili preuzima kao ZIP sa stranice izdanja).
